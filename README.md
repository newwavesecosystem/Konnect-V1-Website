# Konn3ct Integrated Website — React + Tailwind CSS

This edition uses **Create React App / react-scripts**, not Vite.

## Run locally

```bash
npm install
npm start
```

The app opens on `http://localhost:3000` by default.

## Production build

```bash
npm run build
```

## Routes

- `/`
- `/government`
- `/associations`
- `/education`
- `/faith`
- `/corporates`
- `/events-community`

## Technology

- React 18
- React Router 6
- Tailwind CSS 3
- react-scripts 5 (Create React App toolchain)

There is no Vite dependency or Vite configuration in this version.
